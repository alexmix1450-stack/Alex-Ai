ALEX AI - Android starter

इसमें Offline demo chat, Hindi/English interface और Online mode placeholder है।

Android पर:
1. ZIP extract करें।
2. Files को HTTPS hosting पर publish करें।
3. Chrome में अपनी website खोलें।
4. Chrome menu (⋮) > Add to Home screen / Install app चुनें।

महत्वपूर्ण:
- यह installable PWA है, अभी APK नहीं।
- Offline जवाब सीमित demo replies हैं, असली generative AI नहीं।
- Online mode के लिए HTTPS backend बनाकर app.js में ENDPOINT सेट करना होगा।
- API key को app.js या public frontend में कभी न रखें; backend पर सुरक्षित रखें।
- APK बनाने के लिए Android build workflow (जैसे Capacitor/Android Studio) चाहिए।
